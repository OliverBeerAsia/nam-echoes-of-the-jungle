# Historical Reference Guidelines

## Scope

Visual references should align with late-stage Vietnam War context (around 1968) in southern Vietnam environments.

## Visual Authenticity Rules

- Avoid modern anachronisms in props, architecture, and uniforms.
- Keep ARVN/US/local civilian visual distinctions clear.
- Use plausible weathering and material aging for humid tropical conditions.
- Prioritize period-appropriate tool and equipment silhouettes.

## Environment Guidance

- Jungle density should feel humid and overgrown, not sparse parkland.
- Village architecture should favor local materials and construction patterns.
- Military structures should reflect improvised field fortification where appropriate.

## Content Review Checklist

- Uniforms and gear plausible for period/location.
- Signage and symbols plausible for zone/faction.
- No modern packaging, logos, or hardware models.
- Weapons and support props match narrative context.

## Review Cadence

- Run authenticity pass once per milestone zone before final merge.
